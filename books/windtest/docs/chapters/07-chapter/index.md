# 7 展望

风力发电的未来发展需要学术界和工业界共同关注从风力机、电力系统应用到相关政策等多个关键领域。

随着全球适合开发陆上风能资源的区域逐渐趋于饱和，海上风能资源预计将得到更大规模开发。与传统固定式基础风力机相比，漂浮式风力机在深水区域开发风能方面具有巨大潜力，可扩大海上风电的地理开发范围（图[7a](#page-12-0)）。因此，漂浮式风力机技术已受到广泛研究关注[n40](#page-14-1)。在波浪和风不断变化的条件下，平台具有动态特性，使漂浮式风力机的设计较为复杂。此外，在海上风电场与陆上电网之间长距离敷设海底电缆成本较高，也可能面临运行挑战，仍需进一步研究。

为了提高风能捕获能力，风力机的尺寸和容量不断增大，未来还将继续提高（图[7b\)](#page-12-0)）。但大功率风力机需要采用三电平变流器和MMC拓扑等先进电力电子技术，以提高电压等级和功率传输能力。因此，这类风力机可能面临新的问题，包括中压或高压应用中电力电子系统的功率损耗、稳定性、可靠性、绝缘和保护问题，这些也是未来的重要研究方向。

与传统矢量控制相比，先进控制能够提供更优性能。在实际电力系统中，多套风力发电系统之间会发生相互作用[170](#page-16-15)。除评估单机系统性能外，还应进一步研究这些相互作用，并处理和减弱其不利影响。此外，未来对风力发电系统的要求可能发生变化，

例如，为增强频率稳定性，可能增加新的频率或惯量支撑要求，并由此形成构网型控制和跟网型控制等不同控制策略。还应充分研究风力发电系统之间的相互作用以及风力机本身的动态特性，尤其是采用构网型控制时的动态特性。在风电系统高渗透率条件下，并网电网的特性不能简单等效为串联阻抗的理想电网。在先进控制方法广泛投入实际应用之前，必须开展这种系统层面的分析与验证（图[7c\)](#page-12-0)）。

储能对于未来可持续电力系统至关重要，可用于平滑风力发电系统的功率输出。储能作为能量缓冲，可提高风力发电系统提供多种辅助服务的能力[171](#page-16-16)，例如具备GFM能力的频率调节、黑启动、稳定性改善和功率调度。采用储能可避免二次频率跌落和功率降载等关键问题，多功能风储联合系统是一个具有前景的研究方向（图[7d\)](#page-12-0)）。储能技术及其与风能系统协同控制的发展，有望推动风能系统进步。就GFM而言，目前尚无指导工业应用的标准，尽管相关工作正在推进。由于GFM控制依赖能量缓冲，可能带来更高复杂度和成本，因此系统所需GFM控制的最佳比例仍是一个开放问题。

未来风能系统的优化发展还需要开展跨学科研究。数据科学和人工智能（AI）正受到越来越多关注（图[7e\)](#page-12-0)，其应用范围涵盖风速预测、辅助控制设计的参数估计以及系统层面优化[n172,](#page-16-17)[173.](#page-16-18) 可靠性也是风力机未来发展的重要因素。目前，风力机的工业设计寿命通常为20年。通过采用提高可靠性的方法避免高应力运行工况，可以延长风力机寿命[e174](#page-16-19)。例如，针对具体任务设计的物理信息人工智能工具，可用于解决状态监测领域长期存在的难题，提高故障预测能力和可靠性。尽管相关初步探索已经开始，但距离广泛应用仍有较大差距。

除技术问题外，政策也需要进一步完善。海上风电场将构成未来风能系统的主体，其采用HVDC输电线路将电力由海上换流站输送至陆上电网。在这种场景下，海上电网电压由海上换流站中的变流器提供。通常只有风电场连接到海上电网，且不存在其他负荷，因此，此类场景中的并网规范可以不同于传统电网。欧洲已经发布面向HVDC连接电网的新并网规范（图[7f](#page-12-0)），但现有内容仍过于宽泛。进一步细化这些新并网规范，可能是一项具有实际价值且成本效益较高的工作。
