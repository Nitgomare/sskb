# 风力发电系统中的电力电子技术

**Frede Blaabjerg、Meng Chen 与 Liang Huang**

## **摘要**

电力电子技术的发展推动了风电并入电力系统。与传统旋转同步发电机不同，风电通过静止功率变流器接入系统。未来，变流器接口型风力发电机在电力系统中的作用将由被动跟随系统转变为主动参与系统调节，从而提供频率支撑功能，这有助于提升高比例风电、低惯量电力系统的频率稳定性。本文首先回顾过去三十年风能发展的主要成就，随后重点阐述电力电子技术及其先进控制在风电系统中的作用，并从电力系统层面讨论为支撑未来可持续电力系统而提出的新要求。本文还介绍了欧洲正在开展的研究和示范项目，以展示当前风电系统的研究重点，最后讨论进一步改善风能并网所需的未来研究方向。
