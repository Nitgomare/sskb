## 这个网站怎么用

1. 在[课程路线](roadmap.md)中确定本周教材章节和最低输出。
2. 先完整阅读教材对应节；只有在需要直觉、推导或演示时，再从官方课程页打开同名视频。
3. 不复制现成 Notebook：至少重写一次数据管道、模型和训练循环。
4. 用[科研复现工作流](research-workflow.md)保存环境、随机种子、指标和结论。
