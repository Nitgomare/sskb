# 教材第 7–10 章：概率、集成与无监督学习

## 第 7 章 贝叶斯分类器

**先读书：** 贝叶斯决策论、极大似然估计、朴素贝叶斯、半朴素贝叶斯与贝叶斯网。

**辅助视频：** 单元 7，重点对应生成式 / 判别式、贝叶斯定理、极大似然、朴素贝叶斯和拉普拉斯修正。

**输出：** 实现带拉普拉斯修正的朴素贝叶斯，并检查零概率问题。

## 第 8 章 集成学习

**先读书：** 个体与集成、Boosting、Bagging、随机森林与多样性。

**辅助视频：** 单元 8，重点看“好而不同”、Boosting 与 Bagging。

**输出：** 在固定基学习器下比较 Bagging 和 Boosting 的偏差、方差与异常点敏感性。

## 第 9 章 聚类

**先读书：** 性能度量、距离、原型聚类、密度聚类与层次聚类。

**辅助视频：** 单元 9，辅助聚类目标、性能度量、距离计算与方法概览。

**输出：** 对同一数据运行两类聚类算法；说明为什么仅凭二维图不能证明聚类质量。

## 第 10 章 降维与度量学习

本章开始不再假设有配套视频。以教材为主完成 k 近邻、低维嵌入、主成分分析、核化线性降维和度量学习。

**输出：** 手推 PCA 的目标并与库实现核对；报告降维前后的下游指标，而不只展示散点图。
