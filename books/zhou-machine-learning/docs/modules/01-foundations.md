# 教材第 1–3 章：学习的语言与评估

## 第 1 章 绪论

**先读书：** 1.1–1.7。建立样本、特征、标记、假设空间、归纳偏好和泛化的准确含义。

**读完再看：** 学堂在线单元 1“绪论”，重点选看典型机器学习过程、基本术语、归纳偏好与 NFL 定理。

**完成任务：** 用一个自己的科研问题写清样本、特征、标记、任务类型和评价目标；用 150 字解释为什么不存在脱离问题分布的“最好算法”。

## 第 2 章 模型评估与选择

**先读书：** 2.1–2.6，尤其区分训练误差、泛化误差、验证集和测试集，并掌握交叉验证、性能度量与偏差—方差。

**读完再看：** 视频单元 2，按需辅助泛化、过拟合、评估方法、性能度量和比较检验。

**完成任务：** 为一个分类实验预注册数据划分、调参规则、主指标和统计比较方法。

## 第 3 章 线性模型

**先读书：** 3.1–3.7。把线性回归、对数几率回归、LDA、多分类和类别不平衡放在统一框架中理解。

**读完再看：** 视频单元 3，辅助最小二乘、多元线性回归、广义线性模型、对率回归和多分类思路。

**完成任务：** 不调用模型封装，分别用 NumPy 实现最小二乘回归和二分类对数几率回归，并解释损失函数。
