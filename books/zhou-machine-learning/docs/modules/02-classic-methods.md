# 教材第 4–6 章：经典监督学习

## 第 4 章 决策树

**先读书：** 4.1–4.6，抓住划分选择、剪枝、连续值与缺失值处理。

**辅助视频：** 单元 4“决策树”，对应基本流程、信息增益、其他划分准则与预 / 后剪枝。

**输出：** 在同一数据划分上比较信息增益与基尼指数，并用验证曲线说明剪枝的作用。

## 第 5 章 神经网络

**先读书：** 5.1–5.6，重点理解感知机、多层网络、误差逆传播及局部极小。

**辅助视频：** 单元 6“神经网络”。注意它在视频中排第 6，但这里服从教材第 5 章顺序。

**输出：** 手推两层网络的反向传播，再用梯度检查验证实现。

## 第 6 章 支持向量机

**先读书：** 6.1–6.8，将最大间隔、对偶、核函数、软间隔与支持向量回归连起来。

**辅助视频：** 单元 5“支持向量机”，用于基本型、对偶、求解、特征空间映射和核函数。

**输出：** 画出线性可分小数据集的间隔与支持向量，并解释改变惩罚参数的结果。
