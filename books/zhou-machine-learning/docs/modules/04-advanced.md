# 教材第 11–16 章：研究生进阶

这六章以书本、习题和阅读材料为中心，本站不将无可靠对应关系的视频硬配给教材。

| 章 | 阅读抓手 | 研究生输出 |
|---|---|---|
| 11 特征选择与稀疏学习 | 子集搜索、过滤 / 包裹、稀疏表示 | 比较至少两种特征选择策略，并讨论选择偏差 |
| 12 计算学习理论 | PAC、有限假设空间、VC 维、稳定性 | 写一页概念依赖图，标出每个结论的假设 |
| 13 半监督学习 | 生成式方法、半监督 SVM、图方法、分歧方法 | 说明未标记数据“有用”所依赖的结构假设 |
| 14 概率图模型 | 隐马尔可夫、马尔可夫随机场、推断、采样 | 为一个序列或空间问题画图并写条件独立关系 |
| 15 规则学习 | 序贯覆盖、剪枝、归纳逻辑程序设计 | 比较规则模型与树模型的表示和可解释性 |
| 16 强化学习 | MDP、值函数、TD、策略梯度 | 在小型环境中比较值迭代与一种无模型方法 |

## 进阶章节的阅读协议

1. 先写清问题设定与假设，再抄写公式。
2. 每个定理分别记录“前提—结论—不能推出什么”。
3. 阅读章末材料时，选择一篇原始论文核查教材概述。
4. 代码实验报告均值与波动，并保留失败配置。
