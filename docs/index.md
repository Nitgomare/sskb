# 科研新手实用培训

本教程面向刚进入课题组的研究生，重点介绍科研过程中真正需要使用的工具和操作方法。

每个模块均包含：

- 具体工具；
- 实际操作步骤；
- 可复现案例；
- 实践任务；
- 最终提交成果。
